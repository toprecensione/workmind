# WorkMind v2 — Database Schema

**Database:** PostgreSQL 16 + pgvector + uuid-ossp
**ORM:** SQLAlchemy 2.x (async)
**Migrations:** Alembic
**Encoding:** UTF-8
**Timezone:** UTC for all timestamps (with one documented exception in MEDIC)

## 1. Conventions

| Aspect | Convention |
|---|---|
| Primary keys | UUID v4, generated by `uuid_generate_v4()` (pgcrypto/uuid-ossp) |
| Foreign keys | `<entity>_id`, `ON DELETE` mostly `NO ACTION` (explicit cascade where needed) |
| Timestamps | `TIMESTAMP WITH TIME ZONE`, default `now()` |
| Multi-tenancy | Every business table has `org_id UUID NOT NULL` |
| Soft delete | `is_active BOOLEAN` for orgs/users; hard delete elsewhere |
| Enums | Postgres native enum types (e.g. `documentstatus`, `auditeventtype`) |
| Vectors | `VECTOR(768)` for nomic-embed-text embeddings |
| Naming | snake_case, plural tables (e.g. `conversations`, not `conversation`) |

## 2. Extensions

```sql
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";  -- UUID generation
CREATE EXTENSION IF NOT EXISTS "vector";     -- pgvector for embeddings
```

These are required before applying migrations. CI tests create them automatically in `conftest.py`.

## 8. Indexes Summary

Total indexes across all tables: ~40

### High-traffic indexes

| Index | Table | Purpose |
|---|---|---|
| `idx_messages_conversation` | messages | Load conversation history (most frequent query) |
| `idx_documents_org` | documents | Org-scoped document listings |
| `idx_audit_org` | audit_logs | Audit log pagination by date |
| HNSW on `document_chunks.embedding` | document_chunks | Vector similarity search (RAG) |
| HNSW on `memories.embedding` | memories | Memory recall |
| `uq_users_org_email` | users | Login lookup |

### Vector index parameters

```sql
CREATE INDEX ON document_chunks
USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64);
```

These defaults work for ≤100K chunks. Tune `m` and `ef_construction` for larger datasets.

| `0008_conversations_columns` | Add summary, model_preference, archived |
| `0009_totp_2fa` | totp_secret, totp_enabled on users |

### Running migrations

```bash
cd workmind-api
alembic upgrade head            # Apply all pending
alembic current                 # Show current revision
alembic history                 # Show all revisions
alembic downgrade -1            # Roll back one
alembic revision -m "msg"       # Create new migration (manual editing)
```

**Note:** autogenerate is disabled — migrations are handcrafted to ensure correctness with custom types, vector columns, and check constraints.
